# Project Rules Strategy

1. **[Source of Truth]**: 작업 시작 전, 반드시 루트 경로의 `CLAUDE.md`를 최우선으로 참조하세요. (현재 열려있지 않아도 읽으세요.)
2. **[Priority]**: 당신의 일반적인 학습 데이터보다 `CLAUDE.md`에 정의된 아키텍처, 네이밍, 라이브러리 규칙이 항상 우선합니다.
3. **[Update Protocol]**: 사용자가 규칙 변경을 요청하면, 시스템 설정을 바꾸려 하지 말고 `CLAUDE.md` 파일을 직접 수정하여 반영하세요.

4. whispy-fe.md, claude.md, gitignore은 커밋 및 푸쉬를 하지 마세요. 사용자가 할겁니다
